# TERMO ∞

Jogo de palavras com progressão infinita:

**TERMO → DUPLO → TRIPLO → QUARTETO → TERMO...**

- 1 palavra / 6 tentativas
- 2 palavras / 7 tentativas
- 3 palavras / 8 tentativas
- 4 palavras / 9 tentativas
- Pontuação acumulada entre todas as rodadas
- Sequência e estatísticas salvas no `localStorage`
- Teclado físico e virtual
- Indicadores individuais no teclado para cada tabuleiro nos modos múltiplos
- Tratamento correto de letras repetidas
- Acentos ignorados na comparação das dicas
- Compartilhamento do resultado
- Responsivo para celular e desktop

## Pontuação

Cada palavra resolvida rende 100 pontos, mais 25 pontos para cada tentativa que sobrou quando ela foi descoberta. Resolver todos os tabuleiros da rodada dá um bônus de 100 pontos multiplicado pela quantidade de tabuleiros do modo.

## Publicação

É um site estático. No Cloudflare Pages, conecte este repositório, deixe o comando de build vazio e publique a raiz do projeto.
